# Local references

This directory is for local-only inputs used during AnnePad development. With
the exception of this policy file, its contents are ignored by git.

Expected local references may include:

- A legally obtained Pokémon Stadium (US) 1.0 ROM supplied by the user.
- A local HarkinianPad checkout used to study proven iOS shell, touch, file,
  lifecycle, and packaging patterns.

Never commit, upload, package, or redistribute ROMs, save files, extracted game
data, signing credentials, provisioning profiles, or other copyrighted game
assets from this directory.
